# Sound files

Drop short MP3s here with the following filenames — `useSound` looks for them
relative to `/sounds/`:

- `move.mp3` — quiet wood-on-wood click for a normal move
- `capture.mp3` — slightly heavier knock for a capture
- `castle.mp3` — double tap for castling
- `check.mp3` — alert tone when a check happens
- `checkmate.mp3` — definitive end-of-game tone
- `start.mp3` — game-start chime
- `end.mp3` — game-over neutral tone
- `notify.mp3` — generic UI notification

You can grab CC0 / royalty-free sounds from sources like
https://freesound.org or https://lichess1.org/assets/sound/standard/.
